## 🚀 Quick Start

```bash
# Backend
cd server
npm install
cp .env.example .env
# Edit .env - add MongoDB URI and Groq API key
npm run seed
npm run dev

# Frontend (new terminal)
cd client  
npm install
cp .env.example .env
npm run dev
```

Visit: http://localhost:5173
